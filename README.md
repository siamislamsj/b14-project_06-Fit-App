# FitLog — Workout Library

FitLog is a responsive workout library and daily training planner. Users can explore exercises, read instructions, create a plan for today, and save workouts for later. Workout data is loaded from the FitLog API.

## Technologies Used

- Next.js (App Router)
- React
- Tailwind CSS
- daisyUI
- Lucide React
- FitLog REST API
- Browser localStorage

## Features

1. **Workout Library:** Browse exercises with images, categories, equipment, and ratings.
2. **Workout Details:** View descriptions, specifications, and step-by-step instructions.
3. **Today's Plan:** Add up to five workouts and track total exercises, minutes, and calories.
4. **Saved Workouts:** Save exercises for later and access them from the My Plan page.
5. **Workout Management:** Sort workouts, mark planned exercises as done, and remove workouts.
